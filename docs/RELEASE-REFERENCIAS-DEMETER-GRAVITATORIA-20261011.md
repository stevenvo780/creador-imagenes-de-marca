de Humanizar17. Ambas pasan v3→v4; otros campos, perfiles y modos se conservaron.

constituyen masters exclusivos históricos. Deméter conserva fondo transparente,

igualdad píxel exacta a cualquier escala. No se modificaron repositorios fuente.

lectura de bytes exactos después del POST impidieron una aplicación ciega.
